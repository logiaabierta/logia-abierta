## Markdown puro

Este ensayo está escrito en Markdown tradicional. Es útil para artículos rápidos, notas editoriales y páginas evergreen que no necesitan componentes interactivos.

## Cuándo usarlo

Usa Markdown cuando el contenido sea principalmente texto:

- explicaciones conceptuales
- guías breves
- notas históricas
- respuestas directas para búsqueda orgánica

## Relación con MDX

Markdown y MDX pueden convivir en la misma colección. Markdown mantiene el flujo simple; MDX queda disponible para Mermaid, presentaciones y componentes especiales.
