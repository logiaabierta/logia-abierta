## Markdown vivo para piezas especiales

Este ensayo vive en MDX. Eso significa que puede usar Markdown normal, pero también componentes visuales y experiencias interactivas cuando el tema lo merece.

Para SGE, AI Overviews y buscadores generativos, la clave sigue siendo que el contenido principal sea claro, visible, rastreable y útil para humanos.

## Uso recomendado

Usa MDX para piezas evergreen, guías, mapas conceptuales y páginas que necesiten componentes. Usa Sanity para el flujo editorial cotidiano.
